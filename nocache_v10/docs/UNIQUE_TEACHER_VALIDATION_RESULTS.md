# V10 唯一请求 Teacher 与结构替换门禁结果

本报告只使用全局不重复请求。K48 仍是正式基线；本轮没有把未通过门禁的 P10/连接器研究代码冒充成可提交版本，也没有删除任何会造成准确率回退的资产。

## 1. 数据隔离

- 总请求：491,453 对，全部唯一；
- 训练：310,131 行、60 个完整源端点、26 个源区域；
- 独立源：71,397 行、14 个完整源端点、12 个源区域；
- 独立区域：109,925 行、22 个完整源端点、8 个源区域；
- 请求对泄漏、源端点泄漏、独立区域泄漏均为 0；
- 定向覆盖距离 23/24/25/26/27 和 71/72/73，以及 Block/Gap 附近与跨越请求。

另在与定向面板独立的 608,000 条唯一请求上复核 K48：Accuracy 为 **97.937559%**，按源/源区域/目标区域聚类 bootstrap 的保守 95% 区间为 **[97.720880%, 98.116059%]**。该值比重复扩充数据更适合作为泛化参考，但仍不能代替官方十亿条评分。

## 2. K48 定向面板误差

| 面板 | 行数 | Accuracy | MAE/ps |
|---|---:|---:|---:|
| 训练 | 310,131 | 97.282074% | 14.013 |
| 独立源 | 71,397 | 97.784242% | 11.767 |
| 独立区域 | 109,925 | 97.551954% | 13.899 |

这是刻意放大边界、Block 和 Gap 的压力集，不能按行数直接外推官方分布。它用于判断哪里应优化。

最稳定的失分结论：

1. **距离 71/72 是首要断层。** 三个面板的距离 72 Accuracy 分别为 93.531973%、93.672537%、94.145201%；距离 71 为 94.431148%、94.813578%、94.692963%。
2. **33～128 是主要低谷。** 独立 608K 中，33～64 为 96.090002%，65～128 为 97.134736%；257+ 反而为 98.825203%。问题不是“越长越差”，而是 Short/Long 分支边界与局部连接器失配。
3. **单 Block 最难。** 独立 608K 中无 Block 为 98.372913%，单 Block 为 95.911676%，双 Block 为 97.943618%，3+ Block 为 98.512266%。单 Block 绕行/Portal 选择比周期长距离更缺结构。
4. **最弱分支是回退和短路径组合。** 训练集 `normalized_fallback` 为 94.145215%，`short_dual` 为 95.022494%，`short_teacher` 为 95.546238%；两个留出集得到同方向结论。`local_r24` 为 99.326987%～99.580329%，不是当前主矛盾。

## 3. 路径级 Gap 与 Block

在 4,096 条平衡抽样的完整 Dijkstra 路径中：

- 路径 Gap 穿越 19,190 次；
- Block 路径段 336 次，Portal 事件 16,329 次；
- 544 条路径存在真实 Gap 穿越，但端点前缀差为 0；
- 66 条路径经过 Block，但端点包围盒 Block mask 为 0。

因此只按两端坐标计算 Gap、只按端点包围盒判断 Block 都不充分。Gap 必须跟随候选路径逐段计价；Block 必须由实际 Portal/绕行侧别决定。

## 4. 已通过的结构验证

- 反向批量 Dijkstra 与普通精确 Dijkstra：96/96 完全一致；
- P10 上/下方向周期 Portal：每个方向 18,432,000 项逐项回读，均无损；
- 349,248 字节固定索引 `int8` 残差表不保存请求身份，只做一次 fine 读取和至多一次 coarse 回退；三面板增益分别为 +0.064924、+0.019517、+0.033184 个 Accuracy 点；
- x86-64-v3/AVX2、batch 8 与 PGO 候选均通过输出字节一致性门禁。

残差小表的增益为正但很小，不能替代完整结构。它可以作为可选修正，但不是达到 99.9% 的核心。

## 5. 尚未通过：两端局部连接器

当前离线 Teacher 已证明每条样本可用一次正向和一次反向 Dijkstra 得到完整的源端/目标端 1,920 维 Portal 连接代价。抽到的 4 条 Block 样本两端都完全可达，但四条样本产生四种不同向量；当前产物仍然：

- 按请求保存向量；
- 保存请求身份；
- 不是固定次数直接访问；
- 端到端精确核心覆盖率按可部署口径为 0%。

这只能作为 Teacher，不能塞进在线程序。真正需要的资产仍是：

`源结构键 -> 少量入口候选/代价` 与 `入口组 + 目标结构键 -> 少量条件出口/代价`。

结构键只能由端口族、x/y 周期相位、方向状态、Block 侧别和局部位移组成，不能含端点对、请求哈希、历史结果或输入顺序。

## 6. 资产删除结论

校正产物路径后，门禁状态为：

- 三面板残差正增益：通过；
- P10 上/下无损：通过；
- 固定次数、无请求身份、三面板正增益、核心覆盖率至少 99% 的局部连接器：未通过。

所以现在**不得删除**以下已提交资产：

| 资产 | 字节 |
|---|---:|
| `augment48_full110.bin` | 10,022,340 |
| `complete_hull.bin` | 16,097,406 |
| `adaptive_a.bin` | 266,072 |
| `pair30.delta.bin` | 684,272 |
| 合计 | 27,070,090 |

删除它们并不能自动得到精确结构，只会让大量请求落回 94%～96% 的弱分支。必须先让新结构在训练、独立源、独立区域三套面板都覆盖并提升，再生成不含旧资产的新提交包。

## 7. 下一步唯一高收益路径

1. 将连接器 Teacher 从“4 条完整向量”扩大为按结构键去重的周期枚举，训练/独立源/独立区域仍严格隔离；
2. 对入口做 `端口族 × x 相位 × y 周期相位 × 方向 × Block 侧别` 的 Top-K，离线验证正确入口召回；
3. 对每个入口组保存 2～4 个条件出口，而不是独立枚举 1,920×1,920；
4. 在线固定组合 `源连接器 + 一次 P10 + 目标连接器`，对实际候选逐段加 Gap；
5. 三面板 Accuracy 和每请求纳秒同时为正后，才删除 Short48/Hull/旧残差；
6. 最后再接受真实 SoA、AVX2、线程数与 PGO 中能在官方计时口径下降低总时间、且输出逐字节一致的版本。

目前不能诚实地宣称“全部结构替换已经可提交”。本轮完成的是把 Dijkstra、误差定位、P10 无损核心、路径级 Gap/Block 证据和 fail-closed 删除门禁做实，并明确把剩余瓶颈收敛到局部连接器压缩这一项。
