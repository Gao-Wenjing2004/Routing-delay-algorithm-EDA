# V71：二维周期直映表审计与拒绝结论

## 结论

V71 验证了“用固定次数的二维周期数组查询替代 Extension Atlas”这一方向，但当前仿射表示没有通过准确率门槛，不能提交：

- 1.122 GB 的 V69 Base+Hot Atlas 使用 zlib level 1 仍为 974,230,524 B，压缩率仅 86.79%，通用压缩不能把它塞进 100 MB。
- 精确图生成的 `10 × 12 × 象限 × 160 × 160` 二维周期表为 73,728,064 B；原始表加约 13 MB Linux 程序仍低于 100 MB，并且启动时只需直接读取，不再为这部分运行 Dijkstra。
- 近锚点的一步斜率误差很小：二维仿射 MAE 0.560916 ps、最大 19 ps。但该数字不能代表全距离。
- Linux 全距离审计覆盖 364,953,600 个路由状态转移，二维仿射表的抽样竞赛 Accuracy 只有 96.310637%；横向位移 0～16 时只有 88.023296%。
- V71 端到端回放 608,000 条独立 Dijkstra Golden，Accuracy 为 95.707131%，低于 V69 的 98.302758%，因此正式拒绝。

当前可提交基线仍是 V68。V71 研究代码由宏隔离，不改变 V68/V69 数值。

## 1. 为什么近锚点很好、全距离却失败

V71 每条记录保存：

```text
anchor + x_periods × x_slope + y_periods × y_slope
```

在锚点附近，最短路径通常还没有切换骨架，所以单周期误差很小。继续向全芯片外推时，最优路径会改变转向位置和中间方向状态；固定的两条斜率无法表达这种离散切换。全距离审计结果为：

| 范围 | 路由层竞赛 Accuracy | MAE |
|---|---:|---:|
| 全部 | 96.310637% | 26.324 ps |
| `|x| ≤ 16` | 88.023296% | 67.100 ps |
| `17 ≤ |x| ≤ 32` | 96.836604% | 23.539 ps |
| `33 ≤ |x| ≤ 72` | 98.260298% | 16.935 ps |
| `73 ≤ |x| ≤ 104` | 98.837975% | 13.923 ps |
| `105 ≤ |x| ≤ 119` | 98.980507% | 13.122 ps |

因此不能依据锚点附近 0.56 ps 的 MAE 宣称接近满分。

## 2. 端到端独立 Golden

| 版本 | Accuracy | MAE | Exact share |
|---|---:|---:|---:|
| V69，无 Extension | 98.3027576768% | 14.504 ps | 50.718% |
| V71，全范围周期表 | 95.7071313450% | 34.423 ps | 31.310% |
| 变化 | **-2.595626332** | +19.919 ps | -19.408 点 |

几何消融中，`95 ≤ |x| ≤ 119 且 93 ≤ |y| ≤ 192` 的 15,760 条确有 `+0.180340` 子集增益，但折算到 608k 全量只有约 `+0.004676` Accuracy 点。为这点收益增加 73.7 MB 表和额外连接器循环不合算，也没有三套独立面板的正收益证明，因此不生成 V72 门控提交版。

## 3. 体积与冷启动判断

| 资产 | 大小 |
|---|---:|
| V69 运行期 Atlas | 1,122,503,458 B |
| Atlas zlib level 1 | 974,230,524 B |
| V71 原始周期表 | 73,728,064 B |
| 周期表 zlib level 9 | 25,781,946 B |

周期表具备明显可压缩性，但压缩错误模型没有意义。现阶段不能用它替换 Atlas，也不能宣称已经完全消除冷启动。V69 已通过去掉 Extension 把 V68 的约 67.12 s 冷启动显著降到约 21.32 s，但准确率下降约 0.38 点；需要先找到精确的结构表示再去掉剩余 Base+Hot 建表。

## 4. 下一步

下一次长审计不再拟合两轴斜率，而是分开测量：

1. 保持横坐标和路由状态完全精确，只外推纵向 12 周期；
2. 保持纵坐标完全精确，只外推横向 10 周期；
3. 由结果决定容量应优先分配给“精确 x 条件下的纵向闭包”还是相反方向；
4. 只接受固定次数查表，不加入逐请求 A*、Dijkstra 或大 Beam；
5. 新表必须在公开集、独立源、独立区域三套面板都正增益，并报告十亿条时间增量。

若“精确 x + 纵向周期”仍不能接近 99.9%，则说明必须回到 P10 的精确 min-plus 周期闭包和状态感知局部连接器，不能继续增加仿射近似表。
