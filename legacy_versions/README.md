# 历史版本源码归档

本目录保存 V1～V6 的可复现源码、模型头文件和关键小型证据。V7 与 V8 因仍在维护，分别位于仓库根目录的 `submission_v7_20260919/` 和 `srb_prpr_v8/`。

归档原则：

- 保留算法源码、构建/训练脚本、模型清单、关键验证报告；
- 不重复提交可重新生成的百万行预测 CSV、编译缓存和 Windows 可执行文件；
- 不把 624 MiB Atlas 或 1 GiB 以上旧二进制再次写入 Git；大文件以字节数和 SHA-256 登记；
- V2 未找到独立目录，现存证据表明它是 V3 使用的局部 Atlas 基线，因此单独保留说明，复现源码从 V3 归档读取。

完整版本沿革、指标口径、大文件指纹和下一步方向见 [`../docs/VERSION_HISTORY.md`](../docs/VERSION_HISTORY.md)。
