# V20 共享快速架构表正式版

直接提交 `submission_v20_shared_fast_atlas.zip`，不要重新压缩。ZIP 内只有 `bin/estimate`。

## 针对 V18 评测结果的优化

V18 在官方参考平台得到：准确度 97.20、时间分 52.45、一致性 100、总分 90.63。主要时间瓶颈不是查询，而是两个一致性进程分别现场生成同一张 1.86 GB 架构表。

V20 做了两项不依赖请求重复的优化：

1. 基础半径24的最短路搜索外围从48格减为8格，保留输出表的全部源端口、目标端口和位移，没有删减半径72/104的高价值表。
2. Linux 两个评测进程通过文件锁共享 `/tmp/srb_runtime_atlas_v20.bin`。第一个进程原子生成完整表，第二个进程等待后直接映射，不再重复建表。共享文件只含官方架构推导值，不含测试请求或答案。

## 十亿隐藏集

算法仍按“源端口、目标端口、相对位移、Block边界”查询架构表，32 MiB 分块流式读写。十亿条全部不重复不会导致失效，也不会把请求或输出常驻内存。时间分提升幅度取决于官方两个一致性进程是否共享同一 `/tmp`；即使评测平台为进程隔离环境，缩小搜索外围仍会减少每个进程的建表时间。
