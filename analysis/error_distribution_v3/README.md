# 公开 100 万条误差分布结论

主分析对象为 V3 逐行预测，因为它在公开集上的准确度 `95.30855` 与正式提交的
`95.27` 最接近。V4、V6 用于检查结论是否随模型版本改变。所有“失分占比”均按
赛题逐行损失 `tanh(4 * |prediction-golden| / golden)` 计算，同一分组下会严格加总
为全部 `4.69145` 个准确度失分点。

## 主结论

1. 不是距离越长越差。主要失分集中在 **49–256 的中距离**：占 61.73% 的样本，
   却贡献 71.94% 的总失分。真正的超长距离 `257+` 准确度反而达到 97.296%。
2. Block 不是总体主因。没有与 Block 包围盒相交的样本贡献 58.04% 的失分；
   相交样本贡献 41.96%，低于其 47.73% 的样本占比。
3. 但 **短距离且碰 Block** 是明显坏分支：只占 1.95% 样本，准确度 87.976%，
   贡献 5.00% 总失分，单位样本损失是总体平均的 2.56 倍。
4. V3 的距离回退分支覆盖 89.00% 样本并贡献 87.66% 的总失分，因此它是总分提升
   的主战场；不是因为它单位样本特别差，而是覆盖面太大。
5. 最坏离群点却主要来自 Atlas：最坏 1000 行中 863 行是 Atlas，984 行为低估。
   Atlas 总体有 89.06% 完全命中，但少量严重低估形成了很长的坏尾巴。

## 按距离

| Chebyshev 距离 | 行数占比 | V3 准确度 | 总失分占比 |
|---|---:|---:|---:|
| 0–16 | 1.56% | 93.324% | 2.22% |
| 17–32 | 3.86% | 94.832% | 4.25% |
| 33–48 | 5.58% | 95.070% | 5.86% |
| 49–56 | 3.23% | 90.654% | 6.44% |
| 57–72 | 6.79% | 92.070% | 11.48% |
| 73–128 | 21.02% | 94.041% | 26.69% |
| 129–256 | 30.69% | 95.821% | 27.33% |
| 257+ | 27.27% | 97.296% | 15.72% |

`49–56` 是 V3 半径边界后的断层。V6 把该环的准确度从 90.654% 提升到
95.305%，单这一段约贡献 V6 相对 V3 总提升的 46%。

## Block 与 Gap

| 分组 | 行数占比 | V3 准确度 | 总失分占比 |
|---|---:|---:|---:|
| 不碰 Block 包围盒 | 52.27% | 94.791% | 58.04% |
| 碰 Block 包围盒 | 47.73% | 95.875% | 41.96% |
| 只碰 1 个 Block | 16.31% | 93.895% | 21.22% |
| 碰 3 个以上 Block | 18.86% | 97.465% | 10.19% |
| 不跨 Gap | 1.53% | 88.547% | 3.74% |
| 跨 1–2 个 Gap | 12.68% | 91.299% | 23.51% |
| 跨 5 个以上 Gap | 65.62% | 96.470% | 49.38% |

因此也不是“经过的 Block/Gap 越多越差”；相反，少量 Block/Gap 和局部短路径更难。

## 低时延与坏尾巴

- Golden 为 `1000–2999 ps` 的样本占 47.52%，贡献 63.86% 的总失分。相对误差
  评分会放大这类低时延样本的同等绝对误差。
- 最差 5% 的行贡献 32.24% 总失分，最差 10% 贡献 45.84%。因此不能只修复少量
  离群点；中距离回退模型的普遍小偏差仍占大头。
- 低估贡献 51.72% 总失分，高估贡献 48.28%，总体方向基本平衡；但最坏 1000 行
  中 98.4% 是低估，说明 Atlas 的灾难性尾部有明显单向性。

## 与正式 95.27 的差异

若 1 亿条真的是从这 100 万条均匀有放回抽样，V3 预期准确度仍为 95.30855，
95% 抽样波动约只有 ±0.00149 个准确度点。正式结果 95.27 与之相差约 0.03855，
不太可能仅由随机复制导致。这说明正式二进制的实际行为并不与当前 V3 输出完全相同，
或者测评数据/评分细节还有额外变换。上述结构结论在 V4、V6 上仍然一致，所以可作为
优化方向；但若要精确复盘正式提交，仍需在 Linux 上运行那一个正式 ELF 导出逐行结果。

## 输出文件

- `error_distribution.json`：完整三模型统计与所有分组。
- `segment_loss_stats.csv`：可筛选的长表。
- `top_error_rows.csv`：V3 最差 1000 行，含端点、误差、距离、Block/Gap 数和分支。
- `top_port_pairs.csv`：按总失分贡献排序的端口对。
- `block_overlap_stats.csv`、`gap_overlap_stats.csv`：逐个 Block/Gap 的重叠统计；因可重叠，
  这些表中的失分占比不能直接相加。
